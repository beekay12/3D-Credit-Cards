# 3D Credit Cards – Membership Tier Showcase

An interactive 3D credit card showcase built with HTML, CSS and JavaScript. The project features three fictional banking membership tiers: Silver, Gold and Titanium, each with its own card design and exclusive benefits.

Explore the cards through interactive 3D animations, hover effects and card-flipping transitions.

## ✨ Features

- **Three Membership Tiers:** Silver, Gold and Titanium card designs.
- **3D Card Animations:** Interactive perspective and tilt effects that respond to mouse movement.
- **Flip Interaction:** Click a card to reveal its reverse side.
- **Dynamic Lighting:** Mouse-following highlights create a realistic reflective effect.
- **Tier Benefits:** Hover over a card to reveal its associated membership benefits.
- **Responsive Layout:** Flexible card arrangement for different screen sizes.
- **Keyboard Accessibility:** Cards support Enter and Space key interactions.
- **Reduced Motion Support:** Respects the user's operating system motion preferences.

## 🛠️ Built With

- **HTML5** – Page structure and content.
- **CSS3** – Card styling, gradients, animations, transitions and 3D transforms.
- **JavaScript (Vanilla)** – Interactive card flipping, mouse tracking and dynamic effects.

No external libraries, frameworks or dependencies are required.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/beekay12/3d-credit-cards.git
```

### 2. Navigate to the project directory

```bash
cd 3d-credit-cards
```

### 3. Run the project

Open `index.html` directly in your preferred web browser.

Alternatively, use the Live Server extension in Visual Studio Code.

## 🖱️ How to Interact

| Interaction | Result |
|---|---|
| Hover over a card | Reveals membership benefits |
| Move your mouse over a card | Activates 3D tilt and lighting effects |
| Click a card | Flips the card to reveal its reverse |
| Press Enter or Space | Flips the focused card |
